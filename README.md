# 落牌有声 (Echo of Cards)

> 一款极致简洁、零延迟的**纯本地**棋牌 / 桌游计分微信小程序 —— 打开即用，落牌即记分。

## ✨ 特性亮点

- **纯本地、零网络**：数据仅存本机微信本地存储，不采集、不上传任何用户数据，打开即用；
- **零延迟记分**：自绘快捷数字键盘 + 页面零计算架构，落分即时响应；
- **8 种内置玩法**：通用累分、零和局、斗地主、跑得快、目标分、掼蛋·攒分升级、UNO·派对罚分、德州扑克记分；
- **零和自动补全**：零和局只需录前 N-1 人，末位自动补全，提交强制总和为 0；
- **分数平衡校验开关**：开局可配置（默认开启），开启时非零和模式也强制每轮合计为 0，对局中可经 topbar chip 实时切换；
- **日夜双主题**：默认白天（浅色），跟随手机系统日夜自动切换，纯 CSS 实现零 JS 状态；
- **自定义沉浸式导航**：状态栏与胶囊按钮精确避让，导航与页面背景同色一体；
- **完整容错**：撤销末轮、回合流水**左滑废弃**（保留记录不计分，方向锁防误触 + 二次确认）、全量流水可追溯；
- **触感反馈**：按键两档节流震动 + 按压缩放，覆盖键盘 / 按钮 / 卡片；
- **配置驱动扩展**：新增一个玩法 = 在引擎注册表加一条配置，页面与存储零改动；
- **计分屏幕常亮**：计分局自动开启 `wx.setKeepScreenOn`，离开自动关闭。

## 🎮 支持的 8 种模式

| 模式 | id | 人数 | 零和 | 规则一句话 |
| --- | --- | --- | --- | --- |
| 通用累分 | `free` | 2~8 人 | 否 | 每人每轮任意加减分，无约束 |
| 零和局 | `zeroSum` | 2~8 人 | 是 | 前 N-1 人录入，末位自动补全，总和恒为 0 |
| 斗地主 | `landlord` | 固定 3 人 | 是 | 底分×倍数事件（炸弹/火箭/春天各 ×2）连乘结算 |
| 跑得快 | `paodekuai` | 2~4 人 | 是 | 剩余牌数×底分计负分，扣分池归先出完者 |
| 目标分 | `target` | 2~8 人 | 否 | 任一玩家总分达到目标分（默认 500）即提示终局 |
| 掼蛋·攒分升级 | `guandan` | 固定 4 人 | 否 | 2v2 场景按人录入，队伍合计可并入同队一人，先达目标分（默认 1000）终局 |
| UNO·派对罚分 | `uno` | 2~8 人 | 否 | 罚分累计（限非负）、低分获胜，罚分达上限（默认 500）终局 |
| 德州扑克记分 | `texas` | 2~9 人 | 是 | 每手零和结算：前 N-1 人录入每手积分变化，末位自动补全 |

## 📖 使用说明

### 开局

1. 首页选择玩牌模式（8 种模式卡片）；
2. 选择人数（斗地主固定 3 人、掼蛋固定 4 人并自动锁定人数；目标类模式可设置目标分）；
3. 按需修改玩家昵称、点击头像色块循环切换 8 色配色；
4. 按需切换**「分数平衡校验」开关**（默认开启）：开启时每轮全场输赢合计必须为 0，非零和模式也会走「前 N-1 人录入 + 末位自动补全」；
5. 点击「开始」进入计分局；首页下方也会列出所有进行中对局，可随时点击继续。

### 记分 / 撤销 / 废弃

- **记分**：用自绘数字键盘逐位录入本轮积分（支持 ± 正负、退格、清空、下一项切换），点击提交即记一轮，按键带触感反馈；
- **零和录入**（零和局 / 德州扑克记分，以及开启平衡校验的其他模式）：只需录入前 N-1 人，末位玩家自动补全展示，提交时强制校验合计为 0，失败会提示具体差额；
- **斗地主**：输入底分 → 选地主 → 选地主胜负 → 勾选炸弹/火箭/春天倍数事件 → 提交；
- **跑得快**：输入底分与每人剩余牌张数（出完记 0）→ 提交；
- **掼蛋**：4 人逐位录入本轮积分（队伍合计可并入同队一人）；**UNO**：逐位录入本轮罚分（不可为负），最低分获胜；
- **校验切换**：对局中可点击 topbar 上的校验 chip 实时开关平衡校验（内置零和模式恒为常开、不可切换）；
- **撤销**：点击撤销弹出末尾一轮，可无限撤销；
- **废弃**：回合流水行**向左滑动**滑出「废弃」按钮（方向锁防误触），二次确认后该轮标记废弃 —— 保留记录、不计入总分、列表中灰显。

### 归档与历史

- **结束对局**：随时点击结束，确认后归档至历史战绩；目标类模式（目标分 / 掼蛋 / UNO）达标会自动弹出终局结算面板，可选择继续记录或直接归档；
- **历史页**：归档对局按结束时间倒序展示（含大赢家/最优者、目标分信息，低分获胜模式显示「最优者」），点击卡片展开查看全量回合流水；
- **删除**：整局删除（二次确认）；**再来一局**：复制该局的玩家、模式与校验开关配置一键开新局。

### 主题

默认白天（浅色）主题，跟随手机系统日夜设置**自动切换**为深色，无需任何手动设置。

## 🛠 技术栈与架构

- **平台**：微信原生小程序，零外部依赖，原生 JS（ES5 兼容写法）；
- **三层结构**：页面层（只收集输入与渲染）→ 引擎层（`utils/scoreEngine.js`，纯函数、零 wx 依赖、全部操作不可变返回新对象）→ 存储层（`utils/storageKit.js`，全项目唯一接触 `wx` 本地存储的模块）；
- **总分永不落库**：只存每轮增量 `deltas`，总分/排名/大赢家由 `computeTotals / computeRanking / computeBigWinner` 实时重算；
- **方向感知**：模式 `ascending` 元数据驱动排名、最优者与终局方向（低分获胜），缺省降序向后兼容；
- **平衡校验**：对局对象含 `strictZeroSum` 字段（默认开启，旧对局缺字段按开启处理，`schemaVersion` 不变）；
- **数据 Schema**：存储键 `echo_cards_data_v1`，根结构 `{ schemaVersion: 1, active: [], archive: [] }`，`schemaVersion` 不匹配时走预留的 `migrate()` 钩子；
- **主题与导航**：纯 CSS 日夜双主题（`darkmode: true` + `theme.json` + `@media prefers-color-scheme`），`custom-nav` 组件 + `navKit` 度量实现沉浸式导航。

### 如何新增一个玩法

1. 打开 `utils/scoreEngine.js`，在 `MODES` 注册表中新增一个模式对象：

```js
myMode: {
  id: 'myMode',
  name: '新玩法',
  desc: '一句话规则描述',
  playerCount: [2, 6],        // 人数范围
  isZeroSum: false,           // 是否零和
  ascending: false,           // 可选：true 表示低分获胜（缺省降序）
  hasTargetScore: false,      // 可选：需要开局配置目标分
  defaultTarget: 500,         // 可选：目标分默认值
  fields: [/* 输入字段定义，驱动页面输入槽位 */],
  validate: function (inputs, game) { return null; /* 返回错误信息或 null */ },
  settle: function (inputs, game) { return { /* playerId: 本轮增量 */ }; },
  isOver: function (game) { return false; /* 终局判定，目标类可复用 targetStyleIsOver */ }
}
```

2. 将新模式的 id 加入 `MODE_ORDER` 数组（控制首页卡片展示顺序）；
3. 完成 —— 首页模式卡片、计分局输入区与结算流程均自动生效，无需改动页面与存储。同类玩法还可直接复用既有模式的 `fields / validate / settle` 函数引用（参见掼蛋与德州扑克记分的实现）。
